        [比]
        
对比并更新 base

      

      

        

          用 txt_compare.exe 对比 output 与 base 目录下的同名省份文件，生成报告并算出更新方案；
          对比一跑完就按方案刷新应用内参考库（无需重启即可检索）。
          确认后可把方案落到 base：当前库覆盖为 {前缀}+base.csv，
          名称变化 / 撤销 / 疑似撤下的记录转入 base/base_old.csv 归档，
          营业状态变化只覆盖原有内容。
